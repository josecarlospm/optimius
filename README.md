# Optimius

Reference marketing site for **Optimius** — AI-built professional websites for **local shops across Iberia (Portugal + Spain)**.

This is the SiteForge north-star product for the local-shop / Iberia visual language (vine motif, dark zinc surfaces, Geist, emerald/copper accents).

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- `next-intl` locales: **pt** (default), **en**, **es**

## Develop

```bash
npm install
npm run dev
```

## Deploy

Vercel project should use a dedicated Optimius alias (e.g. `optimius.vercel.app`). Do **not** bind `siteforge.vercel.app` to this app — that name belongs to the SiteForge factory (`siteforge-chi-nine.vercel.app`).

Canonical product domain: [https://www.optimius.eu/](https://www.optimius.eu/)
